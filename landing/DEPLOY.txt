PikoPe marketing landing → https://pikope.com/download/
=======================================================

LIVE PATH
  https://pikope.com/download/
  (main domain root stays the Flutter web app)

AUTO DEPLOY
  - Push to landing/** → workflow "Deploy landing (/download)"
  - Or: gh workflow run "Deploy landing (/download)"
  - Full web deploy also re-bundles this folder so /download is not wiped

MANUAL
  Upload landing/index.html + landing/assets/ into public_html/download/

API
  APK + copy: https://adminnew.pikope.com/landing/public
  Admin: https://adminnew.pikope.com/admin/landing
