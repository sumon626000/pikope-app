PikoPe Web — Hostinger deploy (Phase 4)
=======================================

BUILD (local Windows)
  cd pikope-web
  .\setup-local.ps1
  .\deploy-hostinger.ps1

  Subfolder install (e.g. https://pikope.com/play/):
  .\deploy-hostinger.ps1 -BaseHref '/play/'

UPLOAD (MAIN DOMAIN)
  1. Hostinger → pikope.com → File Manager → public_html
  2. Remove old static landing files if any (index.html from marketing site).
  3. Upload ALL files from build/web (or extract deploy zip there).
  4. index.html must be at public_html root.

  Optional subdomain play.pikope.com: same build to that vhost, or use -BaseHref '/play/'.

BACKEND (same admin as APK — adminnew.pikope.com)
  .env on API server:
    CORS_ORIGIN=https://pikope.com,http://localhost:7357
    WEB_APP_URL=https://pikope.com
    WS_PUBLIC_URL=wss://adminnew.pikope.com/ws   (proxy to ws-server; optional)

  Deploy PHP changes: Cors.php, ZiniPay.php, Api.php

DNS
  pikope.com → A record to Hostinger site IP, SSL ON (Let's Encrypt)

PWA
  Users can "Install app" from Chrome menu when manifest + icons present.
  Service worker is generated by Flutter build (offline cache for shell).

CDN (optional)
  Large assets live inside the uploaded build (CanvasKit + assets).
  For heavy traffic, put build/web behind Cloudflare cache rules.

ROLLBACK
  Keep previous zip from pikope-web/dist/; re-upload old files.

VERSION
  Tag git: pikope-web-0.1.0+1 matches pikope-web/pubspec.yaml
