PikoPe — MAIN DOMAIN: https://pikope.com (Play Store style landing)
================================================================

Upload ONLY this folder to pikope.com document root (public_html/).
API + admin stay on https://adminnew.pikope.com (separate PHP deploy).

WHAT THIS SITE DOES
-------------------
- Loads copy, stats, hero, screenshots, and APK download URL from:
  https://adminnew.pikope.com/landing/public
- Default language: Bangla (BN/EN toggle on page).
- APK is NOT stored on pikope.com — upload in admin (see below).

HOSTINGER STEPS
---------------
1) pikope.com → File Manager → public_html
   Upload: index.html + entire assets/ folder

2) adminnew.pikope.com → ensure backend deployed, .env APP_URL set, migrate run:
   https://adminnew.pikope.com/health
   https://adminnew.pikope.com/admin

3) Admin → Landing page (pikope.com):
   https://adminnew.pikope.com/admin/landing
   - Upload APK (.apk) — served as https://adminnew.pikope.com/uploads/landing/pikope-latest.apk
   - Upload hero background + screenshots (up to 8)
   - Edit BN/EN headline, tagline, features, stats, “updated” label
   - Save settings

4) Test landing API (browser or curl):
   https://adminnew.pikope.com/landing/public
   → must include "apkUrl" after APK upload

5) Test site:
   https://pikope.com/
   Download button should point to admin-hosted APK URL.

6) SSL: enable HTTPS for both pikope.com and adminnew.pikope.com.

NOTE
----
assets/config.js apiBase is https://adminnew.pikope.com — change only if API host changes.
Do not put a manual pikope-release.apk on pikope.com unless you also set “APK URL” in admin.
