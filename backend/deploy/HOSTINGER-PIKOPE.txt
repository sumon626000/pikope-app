PikoPe backend + admin — Hostinger
==================================

API + admin: https://adminnew.pikope.com  → public_html/pikope/public
MAIN SITE:   https://pikope.com          → public_html/ (upload duelx/site-pikope.com/* ONLY here)

1) Git deploy or upload into:
     .../public_html/pikope/
     Document root for adminnew.pikope.com:
     .../public_html/pikope/public

2) Copy .env.example → .env and set:
     APP_URL=https://adminnew.pikope.com
     DB_* from hPanel → MySQL
     ADMIN_USER=...
     ADMIN_PASS=...   (12+ characters)
     APP_DEBUG=0
     APP_TEST_HOOKS=0
     CORS_ORIGIN=   (leave empty)
     Optional: FCM_SERVER_KEY=...
     Then: php bin/migrate.php && php bin/doctor.php

3) ZiniPay dashboard → Brand website:
     https://adminnew.pikope.com
     Webhook: https://adminnew.pikope.com/webhooks/zinipay

4) Test:
     https://adminnew.pikope.com/health
     https://adminnew.pikope.com/admin

5) APK (local):
     duelx/.env → API_BASE_URL=https://adminnew.pikope.com
     flutter build apk --release --dart-define-from-file=.env

6) Cron every 5 min:
     php .../pikope/bin/cleanup.php
